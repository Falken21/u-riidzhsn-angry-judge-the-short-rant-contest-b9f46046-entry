A short, furious rant about one of modern life's pettiest humiliations: the
supermarket self-checkout. You scan a single banana and the machine stops
everything, flashes its little red light, and announces to the entire store
that there is an UNEXPECTED ITEM IN THE BAGGING AREA — as if you were caught
mid-robbery instead of buying fruit. The rant escalates that one absurd
accusation with comic precision: the unbothered attendant, the code typed
without looking, and the narrator leaving not with groceries but with a
criminal record in the court of automated retail.

## The entry

> UNEXPECTED ITEM IN THE BAGGING AREA. I scanned a banana—one banana—and the self-checkout locked up, a red light spinning over my head like I was mid-heist. The attendant strolled over, typed a code without looking, and freed me. I came in for milk. I left as a person of interest in a fruit crime, acquitted by a scale that still doesn't trust me.

(347 characters, one line.)

## Run it

```sh
python3 main.py
```

This writes the rant to `/output/entry.txt` with no trailing newline.
